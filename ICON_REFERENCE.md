## 🔎 How to Find Icons

### 1. Browse by Category
Visit https://lucide.dev/icons/ and browse by category

### 2. Search by Keyword
Use the search bar on Lucide's website:
- Search for concept (e.g., "close" → `X`)
- Try variations (e.g., "remove", "delete" → `Trash2`, `X`)

### 3. Common Patterns

**Remove "Icon" suffix:**
- `HomeIcon` → `Home`
- `UserIcon` → `User`

**Simplify names:**
- `MagnifyingGlassIcon` → `Search`
- `Cog6ToothIcon` → `Settings`
- `TrashIcon` → `Trash2`

**Keep PascalCase:**
- `CheckCircleIcon` → `CheckCircle`
- `AlertCircle` (not `alert-circle` or `alertCircle`)

---

## 💡 Quick Tips

1. **TypeScript helps**: Icon names are type-checked
2. **Case sensitive**: `AlertCircle` ≠ `alertcircle`
3. **No "Icon" suffix**: Lucide doesn't use the "Icon" suffix
4. **Multiple variants**: Some icons have numbered variants (e.g., `File`, `FileText`, `FileCode`)
5. **Consistent stroke**: All icons use `strokeWidth={2}` by default

## 📱 Components Reference

### Icons are used in these components:

- `<Button>` - `decoIcon`, `actionIcon`
- `<IconButton>` - `iconName`
- `<MenuItem>` - `iconName`, `iconRight`
- `<Tab>` - `decoIcon`, `actionIcon`
- `<Tag>` - `iconName`
- `<Select>` - `decoIconName` (for options: use `iconName` in `SelectOption`)

### Built-in icons (no changes needed):

- `<Alert>` - Icons mapped automatically
- `<EmptyBox>` - Uses `AlertCircle` internally
- `<Select>` - Chevron handled internally
